# Tom Pesce | Website

Two pages: `index.html` (homepage) and `bio.html` (full bio). Keep both files in the same folder. Upload it to a repo, then Settings > Pages > Deploy from branch > `main` / root.

## Photos
All photos, the logo and the videos load from Tom's existing Squarespace and Vimeo accounts, so nothing extra needs uploading.
If the Squarespace site is ever cancelled, those image links stop working. To be safe long term, save each image into an `images` folder in the repo and swap the URLs in `index.html` for `images/filename.jpg`.

## Contact form
Posts to FormSubmit (formsubmit.co) and emails info@tompesce.com. The first submission sends a one time confirmation email to that inbox; click it and the form is live.
