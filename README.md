# Tom Pesce | Website

Single page site. Everything lives in `index.html`.

## Images (optional)
Create an `images` folder next to `index.html` and add:

| File | What it is |
|---|---|
| `images/tom-portrait.jpg` | Portrait for the Meet Tom section (4:5 ratio works best) |
| `images/client-logos.jpg` | Client logo strip (the old site's Logos.jpg) |
| `images/favicon.png` | Browser tab icon |
| `images/og.jpg` | Social share preview image (1200 x 630) |

Missing images hide themselves, so the site still looks finished without them.

## Contact form
The form posts to FormSubmit (formsubmit.co) and emails info@tompesce.com. The first submission sends a one time confirmation email to that inbox; click it and the form is live.

## Publish on GitHub Pages
1. Upload `index.html` (and the `images` folder) to a repo.
2. Settings > Pages > Deploy from branch > `main` / root.
